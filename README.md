# Rodrigo da Vitoria

Software engineer in Vitória, Brazil. Four years building backend systems where a wrong number becomes a legal problem: a public sector ERP, financial modules and private pension calculations. PHP and Laravel on the application side, Oracle, SQL Server and PostgreSQL underneath, GraphQL and REST in between.

Open to remote roles and to relocation within Europe. [LinkedIn](https://www.linkedin.com/in/rodrigo-da-vitoria)

Most of my work lives in private repositories: the ERP of CRECI-ES, where I have worked since 2024 and made more than 600 commits, and the pension systems at ASPPrev. The projects below are public. `patrimonio` is the prototype of a module I later ported into that ERP, where it runs in production.

## Projects

- **[patrimonio](https://github.com/rodrigovixc/patrimonio)**: asset and inventory management in Laravel, with custody chain, two depreciation methods and signed custody terms. I ported it into the council ERP, where it runs in production with ticket approval and Autentique digital signature.
- **[finance-bolt](https://github.com/rodrigovixc/finance-bolt)**: personal finance tracker built around credit card installments. React, TypeScript, Supabase with forced Row Level Security, Cypress E2E tests. [Live demo](https://finance-bolt.vercel.app)
- **[app-applied-job-tracker](https://github.com/rodrigovixc/app-applied-job-tracker)**: job application tracker. React and NestJS, Postgres Row Level Security enforcing per-user ownership, API e2e tests.
- **[macOs-notch-ticker](https://github.com/rodrigovixc/macOs-notch-ticker)**: StockNotch, live stock and crypto prices with portfolio P&L in the MacBook notch. SwiftUI and AppKit, no dependencies.
- **[built-site](https://github.com/rodrigovixc/built-site)**: redesign of a Portuguese research lab website in Portuguese, English and Spanish. React 19, TypeScript and Tailwind 4, with a script that imports the content from the WordPress REST API and converts images to WebP. [Live site](https://built-site.netlify.app/)
- **[creci-licitacoes](https://github.com/rodrigovixc/creci-licitacoes)**: documentation site for a public procurement system, with specification, legal review, ADRs and interactive diagrams. [Live site](https://creci-licitacoes.netlify.app/)
